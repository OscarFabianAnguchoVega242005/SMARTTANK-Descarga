El problema

El agua no avisa cuando se va a acabar

Con un servicio de acueducto intermitente, muchos hogares dependen de tanques de reserva. Pero nadie sabe cuánta agua queda hasta que abre la llave y no sale nada.

Cómo funciona

Del tanque a tu mano en tres pasos

Una arquitectura IoT sencilla y de bajo costo: hardware embebido, una API en la nube y una app multiplataforma.

01

Sensor en el tanque

Un sensor ultrasónico HC-SR04 mide la distancia hasta el agua. El ESP32 calcula la lectura, la envía por WiFi y vuelve a dormir para ahorrar energía.

  • ESP32
  • HC-SR04
  • Deep sleep
  • WiFi Manager
02

API en la nube

El servidor recibe cada medición, calcula porcentaje y litros según la capacidad del tanque, y guarda el historial de forma segura.

  • Node.js
  • Express
  • PostgreSQL
  • JWT
03

App en tu celular

Consulta el nivel de todos tus tanques, revisa el consumo de las últimas 24 horas y recibe avisos cuando el nivel baja.

  • Flutter
  • Android
  • Tiempo real

Preguntas frecuentes

¿Tienes dudas?

¿Es seguro instalar el APK?

Sí. Android muestra una advertencia cada vez que instalas una app fuera de Play Store; es normal. Descárgala solo desde esta página oficial.

¿Necesito el sensor para usar la app?

Puedes crear tu cuenta y explorar la app sin él, pero para ver el nivel real necesitas el dispositivo SmartTank (ESP32 + sensor HC-SR04) instalado en la tapa de tu tanque.

¿Cada cuánto se actualiza el nivel?

El sensor toma una lectura cada 5 minutos. Si un sensor deja de reportar durante 30 minutos, la app te lo indica con el aviso «Sin señal».

¿Funciona en iPhone?

Por ahora solo está disponible para Android. La app está hecha en Flutter, así que una versión para iOS es posible en el futuro.

¿Cómo actualizo la app?

Descarga de nuevo el APK desde esta página e instálalo encima de la versión anterior. Tus datos se conservan porque están en tu cuenta.
